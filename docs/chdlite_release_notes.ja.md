# chdlite 0.3.0

chdlite は romexplorer とは別にリリースされます。このノートは chdlite のみが対象です。

## 変更点

- **Rust で全面的に書き直し、romexplorer のコアライブラリ上に構築しました。** 0.2.x の C++
  コマンドラインツールと Flutter GUI を置き換えます。chdman と Dolphin のディスク処理は
  romexplorer 本体が同梱しているものと同じネイティブライブラリです。
- **RVZ 対応。** ゲームキューブ / Wii のイメージを RVZ に変換し、RVZ は ISO に展開できます。
- **Wii U と Xbox。** .wud / .wux と鍵から Cemu の .wua を、Xbox 360 のイメージから Xenia の
  .zar を、Xbox のイメージから xemu 用の XISO を作ります。この 3 つはディスクそのものを残さない
  ため、変換前に確認します。「次回から確認しない」と Settings で止められます。
- **CSO と PBP。** .cso は ISO に、PS1 の EBOOT.PBP は cue と bin に展開します。Lite と Comp で
  CHD にでき、Hash は中身をハッシュします。
- **入力は可逆な形式のみ。** .wua・.zar・XISO はディスクが失われているため受け付けません。
- **形式は自動で選択。** CD と GD-ROM は CD CHD、DVD は DVD CHD、ゲームキューブ / Wii は
  RVZ になります。ファイル名ではなくイメージの内容で判定します。
- **1 つのウィンドウに 4 つのモード。** Lite（高速）、Comp（最小サイズ）、Read、Hash から選び、
  ファイルやフォルダーをウィンドウのどこにでもドロップします。CHD と RVZ の設定は Settings に、
  出力フォルダーはメインウィンドウにあります。
- **モードごとに 4 つのコンソールツール。** 実行ファイルにドロップするだけで目的の処理になります:
  `chdlite`、`chdcomp`、`chdread`、`chdhash`。すべての設定はオプションでも指定できます（`--help`）。
- これまでどおり複数ファイルを同時に変換します（ファイルごとにワーカープロセス）。ウィンドウの
  Cancel で CHD 作成を途中で止められるようになりました。
- **Android 版。** 同じ 4 つのモードを Android（arm64）のアプリで使えます。タッチでもコントローラーでも操作でき、モードを選んでからファイルかフォルダーを指定します。変換はバックグラウンドでも続き、進み具合は通知に出ます。
- Windows x64 / arm64、Linux x64 / arm64、macOS arm64、Android arm64 向けビルド。Windows の GUI は単一ファイルです。

## バグ修正

- Ctrl-C やクラッシュ、ウィンドウを閉じたことで変換が途中で止まると、壊れたファイルが残り、次の実行で完了扱いになっていました。ウィンドウを閉じると変換も止まるようになりました。
- 特定のサイズの PS2 / PSP の ISO が音楽 CD と判定されていました。
- 短いジョブが続く間はキャンセルが効かないことがありました。キャンセルで止まったジョブは数に入っていませんでした。
- 読めない設定ファイルは既定値で上書きされていました。今は `chdlite.toml.bak` として残します。
- 非可逆の確認で「No」を選ぶと、ドロップしたものがすべて取り消されていました。「Skip these」で残りを変換できます。大きなフォルダを読む間にウィンドウが固まることもなくなりました。
- `-hs` は CD と DVD に同じハンクサイズを設定していました。今は合う方にだけ設定します。

## 今回のリリースに含まれないもの

- GCZ と WIA の出力。
- chdman 互換のコマンド名（`createcd`、`extractcd` など）と、ハードディスク / raw の CHD。
- 単一 `.bin` での展開オプション（CD は常にトラックごとに 1 ファイル）。
