# rommusic 0.2.0

rommusic は romexplorer とは別にリリースします。このノートは rommusic だけの内容です。

## 変更点

- **ROM から直接書き出せる曲が増えました。** ファミコン・ディスクシステム・ゲームボーイ・PCエンジン・ワンダースワンは、rommusic に同梱のマップがあるゲームなら、原音ファイルなしで ROM から曲を書き出せます。
- **Mac アプリと Linux の AppImage。** macOS 用の `rommusic.app` と、Linux 用の 1 ファイルの AppImage を用意しました。開くとウィンドウが起動します。コンソール版も中に入っています（`rommusic.AppImage rommusic ...`）。
- **ウィンドウのオプションを追加しました。** コンソール版と同じく、曲数の上限、ビット数、Hz で指定するサンプルレート、複数の原音フォルダーを選べます。

## バグ修正

- ファイル名の途中に「;」があるディスクで、音楽ファイルの書き出しが終わりませんでした。
- Android アプリでファイルへのアクセスを許可しようとすると、設定画面が開かず「Java exception was thrown」と表示されました。
- Android アプリのアイコンが rommusic のものではなく、Android の標準アイコンになっていました。
- Android アプリに音楽マップが入っておらず、カートリッジは起動からの検索で見つかった曲しか書き出せませんでした。
- Options の説明に、カートリッジの多くは原音ファイルが必要と書かれていました。
- 同じ名前の入力を 1 つのフォルダーに書き出すと、曲が混ざっていました。2 つ目は「<名前> (2) (music)」に書き出します。
- PSF2 の曲で rommusic が落ちることがありました。
- Android アプリで、zip や 7z に入った ROM とセットを読めませんでした。

# rommusic 0.1.0

## 変更点

- **最初のリリースです。** ROM・ディスクイメージ・ダンプしたフォルダー・原音ファイルをドロップすると、ゲームの BGM を FLAC で書き出します。隣のフォルダーに index.txt と一緒に保存します。
- **ウィンドウ版と Android アプリ。** `rommusic-gui`（Windows・Linux・macOS）と Android アプリでは、ファイルかフォルダー、FLAC か原音、出力先を選んで書き出せます。ほかの設定はオプション画面にあります。
- **コマンドラインのオプション**で、BGM 以外の音も含める、曲数の上限、出力先、CD・DVD・ハイレゾのレート、元の形式での書き出し（音楽ファイル、原音ファイル、スーファミの .spc）を選べます。
- **カートリッジ**は、手持ちの原音ファイルと中身で照合します（`--originals`）。ファミコン（拡張音源も）・ディスクシステム、ゲームボーイ・ゲームボーイカラー、ゲームボーイアドバンス、マスターシステム（FM 音源も）・ゲームギア・メガドライブ・PCエンジン・MSX・ワンダースワン・バーチャルボーイ・ネオジオポケットは ROM から直接、スーパーファミコンは原音ファイルなしでタイトル曲を書き出せます。
- **長さのない原音ファイルの曲**は、音楽の終わりで止まります。最後の無音はなく、繰り返す曲はループを 2 回流してフェードアウトします。
- プレイリストが 0 から数える原音ファイルでも、名前どおりの曲を書き出します。
- **Wii と Wii U：** Wii のディスクと Wii U の .wua に対応します。.wud・.wux とダウンロード版のタイトルは、隣に鍵があれば読めます。
- 対応する機種と形式は README.md にあります。
