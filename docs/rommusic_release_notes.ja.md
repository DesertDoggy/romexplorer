# rommusic 0.1.0

rommusic は romexplorer とは別にリリースします。このノートは rommusic だけの内容です。

## 変更点

- **最初のリリースです。** ROM・ディスクイメージ・ダンプしたフォルダー・吸い出しファイルをドロップすると、ゲームの BGM を FLAC で書き出します。隣のフォルダーに index.txt と一緒に保存します。
- **コマンドラインのオプション**で、BGM 以外の音も含める、曲数の上限、出力先、CD・DVD・ハイレゾのレート、元の形式での書き出し（音楽ファイル、吸い出しファイル、スーファミの .spc）を選べます。
- **カートリッジ**は、手持ちの吸い出しファイルと中身で照合します（`--rips`）。ゲームボーイアドバンスは ROM から直接、スーパーファミコンは吸い出しファイルなしでタイトル曲を書き出せます。
- **長さのない吸い出しファイルの曲**は、音楽の終わりで止まります。最後の無音はなく、繰り返す曲はループを 2 回流してフェードアウトします。
- **Wii と Wii U：** Wii のディスクと Wii U の .wua に対応します。.wud・.wux とダウンロード版のタイトルは、隣に鍵があれば読めます。
- 対応する機種と形式は README.md にあります。
