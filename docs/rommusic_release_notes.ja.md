# rommusic 0.2.0

rommusic は romexplorer とは別にリリースします。このノートは rommusic だけの内容です。

## 変更点

- **ROM から直接書き出せる曲が増えました。** ファミコン・ディスクシステム・ゲームボーイ・PCエンジン・ワンダースワンを追加。（対応ゲームのみ）
- **Mac アプリと Linux の AppImage を追加。**
- **ウィンドウのオプションを追加。** 曲数の上限、ビット数、Hz 指定のサンプルレートを指定可能。

## バグ修正

- ファイル名の途中に「;」があるディスクで、音楽ファイルの書き出しが終わらない問題を修正。
- Android アプリでファイルへのアクセスを許可できない問題を修正。
- Android アプリのアイコンを独自のものに変更。
- Android アプリに音楽マップが入っていない問題を修正。
- 同名の入力を同じフォルダーに書き出すと曲が混ざる問題を修正。
- Android アプリで zip・7z 内の ROM を読めない問題を修正。

# rommusic 0.1.0

## 変更点

- **最初のリリースです。** ROM・ディスクイメージ・ダンプしたフォルダーをドロップすると、ゲームの BGM を FLAC で書き出します。
- **ウィンドウ版と Android アプリ。** `rommusic-gui`（Windows・Linux・macOS）と Android アプリでは、ファイルかフォルダー、FLAC か元の形式、出力先を選んで書き出せます。ほかの設定はオプション画面にあります。
- **コマンドラインのオプション**で、BGM 以外の音も含める、曲数の上限、出力先、CD・DVD・ハイレゾのレート、元の形式での書き出し（音楽ファイル、スーファミの .spc）を選べます。
- **カートリッジ**は、ファミコン（拡張音源も）・ディスクシステム、ゲームボーイ・ゲームボーイカラー、ゲームボーイアドバンス、マスターシステム（FM 音源も）・ゲームギア・メガドライブ・PCエンジン・MSX・ワンダースワン・バーチャルボーイ・ネオジオポケットは ROM から直接、スーパーファミコンはタイトル曲を書き出せます。
- **Wii と Wii U：** Wii のディスクと Wii U の .wua に対応します。.wud・.wux とダウンロード版のタイトルは、隣に鍵があれば読めます。
- 対応する機種と形式は README.md にあります。
