# romexplorer 0.2.1 (alpha)

アルファ版です。リリースの間でデータベーススキーマがアップグレード手段なしに変わることがあります。
ビルドを入れ替える前にバックアップしてください。

## 変更点

**3DS**
- 3DS の ROM の形式変換に対応。
- 鍵は同梱していません。aes_keys.txt（必要なタイトルには seeddb.bin も）を、ファイルと同じフォルダ、romexplorer と同じフォルダ、またはその assets フォルダに用意してください。
- 3DS の ROM のシリアル照合に対応。

**ROM の音声**
- タイトルページを開いたときにそのゲームの ROM の音楽を優先的にインデックスするように変更。
- ROM の音楽のインデックスを小さい順に行い、非対応の ROM はスキップするように変更。
- 独自のサウンドエンジンを使う PS1 のゲームに対応。

## バグ修正

- 一部のディスクイメージで、ROM の音楽のインデックスが終わらない問題を修正。
- コピーで SNES のダンプを変換するとき、サイズと内部ヘッダーでコピーヤーヘッダーの有無が食い違うファイルもそのまま変換していた問題を修正。

**スキャン**
- Linux で、大文字・小文字や「\」区切りが違う cue・gdi・m3u の記述を見落とす問題と、大文字・小文字だけ違う 2 ファイルを 1 つの ROM とする問題を修正。
- 中のフォルダーに設定した種類・機種が親フォルダーのスキャンで無視される問題を修正。
- 再スキャンでフォルダー形式のゲームの読み直し、トラックの分離、シリアル照合の解除が起きる問題を修正。大きなフォルダーでのディスクのまとめを高速化。
- ROM でないファイル（テキスト・画像）は、照合できたときだけゲームにするよう変更。
- スキャンのハッシュで crc32・md5・sha1 のどれか 1 つを必須に変更。xxh3_128 だけで DAT の照合が外れる問題を修正。

**コピー**
- 上書き時に新しいファイルより先に古いファイルを消す問題、残す設定のプレイリストを書き換える問題、大文字・小文字だけ違う 2 ファイルを 1 つに書く問題を修正。

**タイトルの統合**
- バージョンセットの別バージョンどうしや、正規版と非正規版を統合する問題を修正。「すべて承認」で解除済みの統合が戻る問題、監査で外した IGDB リンクが戻る問題も修正。
- 統合済みゲームの別名による Hasheous 照合でタイトルが重複する問題を修正。

**サーバーとジョブ**
- クライアント向けのアート取得でサーバー内部のネットワークに接続できる問題を修正。サイズの上限も追加。
- 「database」「all」の SQLite キャッシュのダウンロードを管理者のみに変更。
- 完全同期の中断でテーブルが半分のまま残る問題、バックアップの取り消し後に書き込み中のまま次が始まる問題を修正。
- 別ドライブへのコピーや別サーバーからの同期が無関係のジョブを待つ問題、データベース再起動後にジョブが二重に始まる問題を修正。

**その他**
- PSF2 のセットで ROM の音楽の処理が落ちる問題を修正。
- Web コンソールと設定画面の一部が英語のままだった問題を修正。
- 10.6 より前の MariaDB は接続時にエラーを表示するよう変更。

# romexplorer 0.2.0 (alpha)

## 変更点

**統合の確認の AI**
- 「Google に聞く」を Ask メニューに変更。Google の AI モード・Claude・ChatGPT・Perplexity を、質問を入れた状態でブラウザーに開きます。
- アプリ内の回答には Gemini・Claude・OpenAI・Perplexity を使えます。それぞれ API キーとモデルを設定します。
- 回答を保存するように変更。「もう一度聞く」で再度取得、ピン留めした回答は自動再取得対象外。
- 保存した回答はデータベースのバックアップに含まれます。

**Config › AI**
- AI の設定タブを追加。
- 保存した回答の件数と、今月と合計の概算費用を表示します。回答は JSON での書き出しと読み込み可能。

**決定版タブの AI**
- 各ゲームのページで、決定版選出にあたりタイトル間の違いを AI に聞けるようになりました。回答には注記と同じ形のランクが付きます。
- 最初の質問の前に費用の注意を表示。Config › AI に各プロバイダーの利用上限のページへのリンクを追加。
- 「AI でまとめて評価」で、複数のゲームのサジェスチョンをひとつのジョブで聞けます。始める前に質問数と概算費用を表示し、回答済みのゲームは飛ばします。
- 評価のあとに新しいバージョンが出たゲームには「評価後に新版あり」と表示し、絞り込みから除くこともできます。

**タイトル: 下位版とバージョンセット**
- 「下位版を隠す」を追加。
- 「バージョンセットから 1 つ」を追加。
- タイトルのページに「バージョン」カードを追加。

**Config › Advanced**
- データベースを壊したりファイルを失ったりするおそれのある操作をまとめたタブを追加。データベースの最適化は、ジョブとデータ › DB からここに移動。

**ROM の音声**
- タイトルページで ROM の中の音楽を再生可能に。（ディスクのゲームの CD 音声トラックと、ニンテンドーDS・3DS のサウンドアーカイブ）
- 設定で再生トラックの基準を調整可能。
- タイトルページのプレーヤーに「この曲を流さない」ボタンを追加。
- 再生のためにデコードした ROM の音楽をメモリキャッシュ機能（設定 › 音声、既定 256 MiB）。
- プレーヤーのノーマライズ機能の調整。
- プレーヤーでクロスフェード可能に（初期値 2000ms、0 でオフ）。
- 曲の最後の無音部をカットするように変更。
- タイトルページの音楽を既定でオンに変更。初回起動時、言語の次に音楽を流すかどうかを聞きます。自分の音声がないタイトルでは、既定でランダムな曲を流します。

**統合の確認と統合タイトル**
- カードのリリースを、正しいタイトルへドラッグして移せるようにしました。「+」に置くと新しいタイトルを作成可能。
- 採用・却下したカードも、状態フィルターで表示できます。既定では表示しません。
- 分割も編集 › 統合タイトルに記録し、そこから元に戻せるようにしました。この更新より前に統合の確認で分割したものも一覧に加えます。

**リリースの統合**
- 別々に登録されている同じゲームのディスクを選び、「ひとつのリリースに統合」でまとめられるようにしました。

**スキャン**
- ファイルのページに「このファイルを再スキャン」を追加しました。ROM のほかのファイルと一緒に読み直し、そのゲームをすぐリリースに照合します。
- ファイルのページに、リンク先のリリースとタイトルを表示するように変更。

## バグ修正

- 単語の途中にハイフンがある名前が IGDB の表記と照合されず、IGDB にマッチしないゲームがあった問題を修正。
- SNES と NES の IGDB 同期で日本のみ発売のゲームが漏れていた問題を修正。
- IGDB のリンクを解除しても IGDB の別名がタイトルに残り、削除もできなかった問題を修正。リンク解除で消えるようにし、別名は ✕ で個別に削除できるようにしました。
- 手動で解除した IGDB のリンクが、「メタデータを更新」で再びリンクされていた問題を修正。自分でリンクし直すまで解除したままになります。
- RetroAchievements のサブセット（チャレンジ、スピードランなど）がゲームのタイトルに入り、別バージョンが 1 つのタイトルにまとまることがあった問題を修正。
- 統合の確認で統合したものを元に戻しても、提案が統合の確認に戻らなかった問題を修正。
- 手動で統合済みのタイトルの提案が、統合の確認に残っていた問題を修正。
- 海賊版や非公式のゲームが、市販ゲームのタイトルに統合されていた問題を修正。
- 「別のゲームが混在」のカードで、別リージョンの海賊版や非公式のゲームがタイトルに残っていた問題を修正。
- 「別のゲームが混在」のカードが、名前の前に番号が付いたリリース（「0743 - …」）を別のゲームとして扱っていた問題を修正。
- 統合の監査などのジョブの進行度を詳細表示するように修正。
- Windows arm64 版と Linux arm64 版で、Wii U・Xbox・Xbox 360 のイメージの変換、PBP の読み込み、ROM の音楽の再生ができなかった問題を修正。
- DAT に載っているファイルが、リリースにもタイトルにもリンクされないままになる問題を修正。

- CHD・RVZ の再圧縮と、cue から CHD への変換に対応。
- NES と SNES のヘッダーの追加／除去に対応。

- デバイスへのコピーに対応。

**カタログ**
- MariaDB を同梱。
- Redump・MAME-Redump・RetroAchievements・RetroBIOS・No-Intro・TOSEC の DAT に対応。
- ハッシュと名前での照合に対応。
- リリースとタイトルの統合に対応。
- Hasheous・EmuReady のメタデータに対応。
- IGDB・TheGamesDB・SteamGridDB・MobyGames・ScreenScraper・RetroAchievements のメタデータとメディアに対応。
- ファイルスキャンとプロバイダーの一括同期のジョブに対応。

**サーバーとアプリ**
- REST API。
- TLS に対応。
- レスポンス圧縮に対応。
- `/app/` の Web GUI。
- デスクトップアプリ。
- サービスインストーラー `install.sh` / `install.ps1`。
- バックアップ。
