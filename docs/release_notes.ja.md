# romexplorer 0.2.0 (alpha)

アルファ版です。リリースの間でデータベーススキーマがアップグレード手段なしに変わることがあります。
ビルドを入れ替える前にバックアップしてください。

## 変更点

**統合の確認の AI**
- 「Google に聞く」を Ask メニューにしました。Google の AI モード・Claude・ChatGPT・Perplexity を、質問を入れた状態でブラウザーに開きます。自分のアカウントのまま使えます。先頭に来るものは Config › AI で選べます。
- アプリ内の回答には Gemini・Claude・OpenAI・Perplexity を使えます。それぞれ API キーとモデルを設定します。出典が返ってくれば表示します。
- 回答は保存するようにしました。同じカードを開くと、保存した回答を日付とモデル付きで表示します。「もう一度聞く」で置き換えられ、ピン留めした回答は残ります。別の言語の回答しかないときはそれを表示し、新たに費用をかけずに「〜で聞く」ボタンを出します。
- 保存した回答はデータベースのバックアップに含まれます。

**Config › AI**
- AI の設定タブを追加しました。プロバイダーとモデル、Ask メニューの先頭のリンク、テストボタン付きの API キー（データ › プロバイダーから移動）、編集できる単価表があります。
- 保存した回答の件数と、今月と合計の概算費用を表示します。回答は削除（全部または機能ごと、ピン留めは残すこともできます）、JSON での書き出しと読み込みができます。

**ROM の音声**
- タイトルページで ROM の中の音楽を流せるようにしました。CD プレーヤーのようにディスクイメージから直接再生します。CD の音声トラックと、ディスク内の音楽ファイルに対応します（PlayStation・サターン・ドリームキャスト・ゲームキューブ・Xbox・Xbox 360・PSP など、ダンプしたフォルダーも）。WMA・XMA・ATRAC3 の音楽も再生できます。先に音声タブで「ROM の音声を索引」を実行してください。zip・7z と Wii のディスクはまだ読めません。
- 設定で、タグ付きの音声・ROM の音楽・その両方のどれを流すか、ジングルや効果音も流すか、持っていないタイトルで何を流すか（リメイクの元作品などの別バージョン、またはランダム）を選べます。
- 別のタイトルページを開くまで、ほかの画面でも音楽を流し続けられます。
- ROM 内のタイトルムービーなど、動画の音声も流せます。既定ではオフで、タイトルページごとにオン・オフを切り替えられます。
- DS と 3DS のカートリッジも読みます。DS はサウンドアーカイブ内の音楽、3DS は復号済みイメージの音楽ファイルに対応します。
- ゲームによく使われるアーカイブ（CRI の CPK、AFS、ゲームキューブの .arc・.szs）の中の音楽も見つけます。
- PSP のムービー（.pmf）の音声も、ほかのタイトルムービーと同じように流せます。
- ボイスは長さにかかわらず BGM に数えなくなりました。ループしない曲は 1 分以上で BGM とします（CD の音声トラックは 20 秒以上）。ファンファーレや ME（ミュージックエフェクト）の名前のファイルはジングルとして扱います。最初の短い音声トラック（「ゲーム用のディスクです」という注意の音声）は効果音として扱います。
- ゲームのフォルダーに置いた音楽の吸い出しファイル（NSF・SPC・GBS・VGM・HES・KSS・AY・SAP・ゲームギアの SGC、zip のままでも可）もタイトルページで流せます。曲名と長さはプレイリストから読みます。
- 吸い出しファイルのライブラリーに対応しました。設定 › 音声でフォルダーを指定すると、「ROM の音声を索引」が各セットを中身で ROM と照合します。名前が違っても、地域違いの ROM すべてで流せます。
- ゲームボーイアドバンスの曲を、吸い出しファイルなしで ROM から直接流せます。任天堂標準のサウンドエンジンを使うゲーム（およそ半数）が対象です。
- 再生のためにデコードした ROM の音楽をメモリに置くようにしました（設定 › 音声、既定 256 MiB）。あふれた曲はディスクの音声キャッシュに移します。tier 1 キャッシュのフォルダーを設定していれば、そこを使います。

# romexplorer 0.1.8 (alpha)

アルファ版です。リリースの間でデータベーススキーマがアップグレード手段なしに変わることがあります。
ビルドを入れ替える前にバックアップしてください。

## 変更点

**メディア**
- 新しいデータベースでやり直したとき、メディアフォルダーにあるアートをダウンロードし直さずに使うようにしました。足りない分だけをダウンロードします。初回起動時に使うかどうかを確認します。あとから設定の media_reuse_existing で変えられます。

**ジョブ**
- ジョブ一覧の先頭に No. 列を追加し、種類と ID をその次に並べました。
- 待機中のジョブに「次に実行」ボタンを追加しました。選択したジョブにも使えます。同じレーンで実行中のジョブが終わるとすぐに始まります。ほかのレーンには影響しません。

**ハッシュ照合**
- Hasheous だけをオンにしたハッシュ照合でも、PlayMatch のときと同じく、照合できたものの IGDB データとアートを取得します。
- 設定の serial_match で、ファイル名のシリアルを使うかをプラットフォームごとに選べるようにしました。選ばなかったプラットフォームは、ファイル名のチェックボックスに従います。

**統合の確認**
- Gemini の回答と「Google に聞く」が UI の言語で返ってくるようにしました。
- 問い合わせに失敗したときは理由を表示します。証明書やタイムアウト、モデル、使い切ったクォータがわかります。そのモデルに無料枠がないキーは、そのように表示します。
- モデルの一覧を読めなくても Gemini に問い合わせます。クォータのエラーでは、次の Flash モデルで一度だけ試します。

**決定版とクロスプラットフォーム**
- IGDB の ID があるタイトルだけを表示します。タイトル ID の名前のままの Wii U タイトルは、決定版タブに出なくなりました。

## バグ修正

**コレクション**
- 決定版タブの検索で、先頭のタイトル自身の名前しか見つかりませんでした。どの版の名前でも、地域名や別名でも見つかるように修正しました。

# romexplorer 0.1.7 (alpha)

アルファ版です。0.1.x の間はデータベーススキーマがアップグレード手段なしに変わることがあります。
ビルドを入れ替える前にバックアップしてください。

## 変更点

**Wii U**
- コピー時に .wux / .wud と鍵から Cemu の .wua を作れるように。作った .wua はスキャンで元のディスクと同じ DAT の項目に照合されます。
- .wua と .wux の両方があるリリースは、どちらをコピーするか Config › Copy で選べます（既定は .wua）。

**Xbox / Xbox 360**
- コピー時に Xbox 360 のイメージから Xenia の .zar を、Xbox のイメージから xemu 用の XISO を作れるように。.zar はスキャンで元のディスクと同じ DAT の項目に照合されます。

**シリアル照合**
- DAT にハッシュがない .cia・.xiso・.wua・.zar を、ヘッダーのシリアルでハッシュ照合にひも付けられるように。このひも付けには「シリアル照合」の印が付きます。対象の形式と、コピーのマニフェストやファイル名のシリアルも使うかは、設定の serial_match で選べます。
- .vpk・Vita のアプリフォルダ・Switch の .nsp もシリアルで照合します（既定でオン）。.pkg・.psv・PS1/PS2/PS3 のディスクも選べます（DAT にハッシュがあるので既定はオフ）。

**PlayStation**
- .cso と PS1 の EBOOT.PBP をスキャンできるように。中の ISO や cue とトラックで照合します。
- コピー時に PS2 / PSP の ISO を .cso に圧縮できるように。

**Vita とダウンロード版**
- Vita の .pkg・.vpk・.psv・ゲームカードのイメージ・アプリフォルダを認識し、タイトル ID を読みます。サブフォルダのある PS3 / PSP のゲームフォルダは 1 本のゲームとして扱います。
- パッケージがゲーム本体・アップデート・追加コンテンツのどれかを表示します。設定の scan_pkg_titles をオンにすると、PS3 / PSP の .pkg の中のタイトルも読みます（既定はオフ）。
- Switch の .nsp・.nsz・.xci・.xcz を認識します。.nsp は中の NCA ごとにハッシュを取るので、No-Intro のダウンロード版 DAT と照合できます。

**RetroAchievements**
- ファイルの MD5 とは別の RetroAchievements 用ハッシュを使う機種（NES、SNES、N64、PC エンジン、DS、ディスク機）でも、スキャンでそのハッシュを求めます。ハッシュ照合はこのハッシュでもひも付けます。zip のカートリッジや CHD・RVZ・CSO・PBP のディスクは、展開せずにメモリ上で読みます。

**CHD**
- CHD のヘッダーとトラック一覧を内蔵リーダーで読むようにしました。CHD の変換中でもスキャンが待たされません。既定では chdman で照合し、違いがあればスキャン結果に表示します。報告に使ってください。設定の chd_reader で chdman のみ、または内蔵リーダーのみ（今は非推奨）に切り替えられます。

**DAT の取り込み**
- 新しい DAT でファイルが変わったり載らなくなったりしても、古いファイルは削除せず「置き換えられたファイル」としてリリースのページに残します。再び載せた DAT を取り込むと元に戻ります。途中で切れた DAT や、一度に 2% を超えるファイルを外す DAT では何も外しません。

**タイトル**
- コレクション › タイトルで、タイトルをリリースの種類ごとに分けて表示します。通常版・デモ・ベータ・プロトタイプ・非ライセンス・アフターマーケットはそれぞれ 1 行、ハック・MOD・海賊版は 1 本ずつ 1 行です。翻訳は 1 行にまとめ、言語をバッジで示します。
- 行をセットに追加したりコピーしたりすると、その種類のリリースだけが対象です。通常版がなくてもデモで代わりにすることはありません。タイトルのページには今までどおり全リリースを表示します。
- タイトルの中では、製品版がすべてデモ・ベータ・プロトタイプより先に並びます。
- 新しい設定 release_unlicensed で、非ライセンスのリリースを通常版と同じ行にまとめられます。

**決定版**
- コレクションに「決定版」タブを追加しました。移植・リメイク・リマスター・完全版や収録コレクションを、ゲームごとに 1 行にまとめます。各行は最新の版を先頭に表示し、元のゲームを先頭にも切り替えられます。2 枚表紙のグリッドもあります。
- 版はカタログの中から選びます。DAT にない PC・PS5・Switch 2 などの版は、そのプラットフォームの IGDB データを同期すると、持っていないゲームとして表示します。新しい設定 definitive_fetch_versions で、ディスクにあるゲームの他の版を取得することもできます（既定はオフ）。
- プラットフォームの優先順に「PC（決定版タブ）」を追加しました。新しい PC 版の位置を決められます。版の順番はゲームのページでドラッグして並べ替えられます。
- タイトルのページで元のゲームと関係（移植、リマスター、完全版など）を設定できます。同じゲームの他の版と収録コレクションも表示します。
- 旧版に最新版にない要素があるゲームには注記が付きます。注記のランクで絞り込めます。
- 決定版タブのゲームを、決定版としてセットに追加できます。設定 copy_definitive で、持っている中で最も良い版をコピーするか、決定版だけをコピーするか（持っていなければ何もコピーしない）を選べます。
- セットの一覧に種類の列を追加しました。D（決定版）、C（クロスプラットフォーム）、T（タイトル）、R（リリース）で表示します。グリッドでは同じ文字を表紙に表示できます。
- 新しい設定 collection_hidden_tabs で、使わないコレクションのサブタブを非表示にできます。タイトルとリリースは常に表示されます。

**表示言語**
- 初回起動時に表示言語を選べるようになりました。アプリと Web コンソールの右上の言語メニューで、いつでも切り替えられます。
- フランス語・スペイン語・イタリア語・ポルトガル語・ドイツ語・韓国語・ポーランド語の表示を追加しました。

**DAT の同期**
- 新しい設定 dat_sync_platforms で、DAT の同期をスキャンで見つかったプラットフォームや、チェックしたプラットフォームだけに絞れます。Redump と MAME Redump は対象外のファイルをダウンロードしません。No-Intro と TOSEC はパックから対象の DAT だけを取り込みます。
- メタデータ取得のプラットフォーム一覧は、この設定のプラットフォームにチェックが入った状態で始まります。名前の下にチェックボックスを置き、すべてチェック・すべて解除と、メーカーや機種の種類ごとのボタンを付けました。
- ジョブとデータ › DAT の同期画面にも同じプラットフォーム一覧を表示します。設定のプラットフォームにチェックが入った状態で始まり、今回だけ外すこともできます。
- 音楽 CD・映像ディスク・説明書やスキャン・ソースコード・アバターや壁紙など、ゲーム以外の DAT や、プラットフォームが分からない DAT も、チェックして選べます。「すべて」以外では、チェックしたものだけを取り込みます。
- 「ダウンロード済みをインポート」で、zip 全体を取り込むか、プラットフォームを選んでから取り込むかを選べます。

**カタログの同期**
- クライアントの更新同期では、前回の同期以降にメインサーバーで変わった行だけを取得します。これまでは少しでも変更のあったテーブルを丸ごと取得していました。スキャンや整合性チェックの日時だけが変わった行は取得しません。
- ソースに「完全同期」ボタンを追加しました。すべてをもう一度取得します。クライアントの内容がおかしくなったときに使います。

**スキャン**
- スキャン・クイックスキャン・再ハッシュの後のハッシュ照合で、スキャン画面でチェックした DAT・Hasheous・PlayMatch を使います。チェックの状態は記録されます。
- タイトル統合の 7 つのステップを、スキャン画面の「実行中」に表示します。完了したステップは結果と所要時間、実行中のステップは進み具合がわかります。ジョブ一覧にもステップを記号で表示します。アプリでもスキャン画面から実行中のスキャンを取り消せます。

**コピー**
- wua・zar・xiso を出力に選ぶと確認を表示します。元のディスクイメージには戻せません。「次回から確認しない」で止められ、Config › Copy で元に戻せます。
- コピー先に既にあるファイルは、既定でスキップします。コピーを押すと該当するファイルを一覧にし、スキップ・名前を変更・上書きをファイルごとか、まとめて選べます。

**メディア**
- PS1 / PS2 のカバーを xlenore の psx-covers・ps2-covers から取得できるように。リリースのシリアルで探すので、廉価版や特装版にもそれぞれのカバーが付きます。ボックスの表面は既定で取得し、3D ボックスは media_download でチェックすると取得します。IGDB などとの優先順位は media_priority で決めます。

**スキャン**
- トラックが横にない cue・gdi（CHD にして別の場所に置いた場合など）は、エラーではなく警告にしました。スキャンは失敗になりません。
- ジョブとスキャンの一覧で、終わったジョブに「結果」ボタンを付けました。スキャンのエラーと警告を一覧で見られます。

## バグ修正

**セキュリティ**
- /app/ の Web 版から、サインインなしでサーバーが読めるファイルをすべて読み出せました。
- アートの取得がローカルネットワーク内のマシンに向けられることがありました。

**ジョブ**
- Linux でジョブを同時にいくつも動かすと「Too many open files」で失敗することがありました。起動時に開けるファイル数の上限を引き上げるようにしました。
- Linux で ZFS のプールを HDD と判定していたため、NVMe や SSD のプールでもスキャンとコピーが大きいファイルを 1 つずつしか読みませんでした。scan_parallel_files と copy_parallel_files で、ドライブの種類を手動で指定することもできます。
- タイトル統合の 4 つ目のステップで、進行状況のバーが戻ることがありました。

**スキャン**
- 壊れた CHD・RVZ・CSO・PBP でスキャンが止まることがありました。キャンセル後も読み込みが続いていました。
- 大きなファイルのハッシュ計算でメモリがあふれることがありました。親フォルダを指すリンクは何度もスキャンされていました。
- Shift-JIS や BOM 付きの cue、列をそろえた gdi、`./Disc 1.chd` のような m3u の行を読めませんでした。
- CRC32 だけを残す設定では、再スキャンでフォルダの DAT 照合が消えていました。読めないファイルは削除扱いになり、DAT で直ったハッシュも反映されませんでした。
- RetroAchievements のハッシュを求めるスキャンで、N64・SNES・NES・PC エンジン・DS・ディスクのイメージを、同時処理の設定にかかわらず 1 つずつ読んでいました。
- 小さいファイルが多いスキャンで、進捗バーの下に出る読み込み中のファイルがほとんど更新されませんでした。ファイル名が長いと、進捗の行が途中で切れていました。
- PSP や PS1 クラシックの .pkg を Vita のゲームと判定していました。
- PSP のゲームや DLC の .pbp がハッシュされていませんでした。

**タイトル**
- ハック・MOD・パッチ版が通常版と混ざって並び、デモがほかの地域の通常版より先に来ることがありました。タグが複数ある名前は 1 つしか記録されていませんでした。

**コピー**
- 既定の「名前を変える」で、コピー先にある別のファイルを上書きすることがありました。元のフォルダに変換すると元のファイルが消えることもありました。
- 1 つのゲームの別々のフォルダにある同名ファイルが失われていました。cue と bin の zip はファイルごとに別の zip になっていました。
- キャンセルしたコピーは、コピー済みのファイルを記録していませんでした。再開したコピーはサイズが合うだけのファイルを完了扱いにしていました。
- RetroAchievements や TheGamesDB の ID をタイトルにひも付けると、全プラットフォームのリリースにひも付いていました。
- raw（展開）形式を選んでも zip や 7z がそのままコピーされていました。中のファイルに展開するようにしました。

**バックアップと同期**
- キャンセルしたバックアップが空のまま残り、正常なバックアップが押し出されることがありました。失敗したモバイル用キャッシュの書き出しも一覧に残っていました。
- 別のタイトルへ移したリリースや外したキーワードが、同期先に残っていました。
- クラッシュで空の鍵ファイルが残ると、サーバーが起動しなくなっていました。

**ハッシュ照合**
- 同じゲームが複数の DAT（TOSEC と No-Intro など）で一致すると、先に取り込んだ DAT にひも付いていました。リリース名の優先順位に従うようにしました。

**DAT の同期**
- Redump のダウンロードリンクが変わり、Redump の DAT 同期が失敗していました。No-Intro もサイトに利用規約への同意画面が加わり、ダウンロードボタンの名前も変わったため、同期できなくなっていました。No-Intro のサイトがメンテナンス中・アクセス制限中のときや、アクセスが遮断されているときは、そのことを表示します。No-Intro のページの表示が遅いときは待ってから再取得し、想定外のページはエラーにその内容を表示します。

**スキャン**

- `sheet_style`（既定は Redump）が、CHD の cue/gdi を作り直すすべての場面と、GD-ROM を cue（Redump）と

- ハッシュ照合を「新規」と「すべて」に分けました。「すべて」は作り直すリンクを外してから、すべてのゲームを照合し直します。手動のリンクは残ります。

# romexplorer 0.1.0 (alpha)

アルファ版: 0.1.x のリリース間でデータベーススキーマが変わることがあり、移行手段はありません。

## パッケージ

| プラットフォーム | サーバー | デスクトップ | アーカイブ |
|---|---|---|---|
| windows/x64 | ✓ | ✓ | zip |
| windows/arm64 | ✓ | ✓ | zip |

| linux/x64 | ✓ | — | tar.gz |
| linux/arm64 | ✓ | — | tar.gz |

`server` は MariaDB と Web GUI を同梱し、`desktop` は専用の MariaDB を持つ GUI アプリです。

## 機能
**ROM の処理**
- ファイル内容からのプラットフォーム判定: カートリッジ、ディスクイメージ、ディレクトリ形式のゲーム、PKG。
- CHD の展開と作成（CD、GD-ROM、DVD。zstd、lzma、zlib、flac、huff）。
- CHD のストリーミング展開と並列ランダムアクセス読み込み。
- RVZ の展開と再圧縮（5 種のコーデックすべて）。ISO から RVZ、WIA、GCZ を作成。
- 同梱の 7-Zip による zip と 7z（Deflate は zlib-ng でデコード。zip/7z のサンプル往復は macOS では未テスト）。
- ハッシュ: CRC32、MD5、SHA-1、SHA-256、XXH3、RetroAchievements のハッシュ。
- 展開 → ハッシュ → 再圧縮を 1 パスで: CHD の再圧縮、RVZ の再圧縮、cue セットから CHD。
- NES と SNES のヘッダー追加／除去。
- cue／GDI シートの検査と修正。
- デバイスへのコピー（FAT で安全なファイル名とプレイリスト付き）。

**カタログ**
- 同梱の MariaDB: 初期構築、マイグレーション、最小権限のアプリ用ユーザー。
- DAT のダウンロードとインポート: Redump、MAME-Redump、RetroAchievements、RetroBIOS。
- DAT のダウンロードとインポート: No-Intro、TOSEC（macOS では未テスト）。
- ハッシュ優先、名前は次点の照合。
- リリースとタイトルの統合（監査と分離付き）。
- メタデータの取得: Hasheous、EmuReady。
- メタデータとメディアの取得: IGDB、TheGamesDB、SteamGridDB、MobyGames、ScreenScraper、RetroAchievements（macOS では未テスト）。
- バックグラウンドジョブ: ファイルスキャン、プロバイダーの一括同期（一括同期は macOS では未テスト）。

**サーバーとアプリ**
- トークン認証とパスワード認証付きの REST API。
- 自己署名証明書による TLS とクライアント側のピン留め。
- zstd／gzip によるレスポンス圧縮。
- `/app/` で提供される Web GUI。
- データベースをプロセス内で動かすデスクトップアプリ（macOS: 起動してデータベースを開始することのみ確認）。
- 初回セットアップ付きのサービスインストーラー `install.sh` / `install.ps1`（macOS では未テスト）。
- zstd の zip で書き出すバックアップ。
