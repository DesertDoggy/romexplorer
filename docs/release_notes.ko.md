# romexplorer 0.2.0 (alpha)

알파 버전입니다. 릴리스 사이에 데이터베이스 스키마가 업그레이드 수단 없이 바뀔 수 있습니다.
빌드를 바꾸기 전에 백업하세요.

## 변경 사항

**통합 검토의 AI**
- "Google에 묻기"가 Ask 메뉴로 바뀌었습니다. Google AI 모드, Claude, ChatGPT, Perplexity를 질문이
  입력된 상태로 브라우저에서 엽니다.
- 앱 안의 답변에는 Gemini, Claude, OpenAI, Perplexity를 쓸 수 있습니다. 각각 API 키와 모델을
  설정합니다.
- 답변을 저장합니다. "다시 묻기"로 새로 받을 수 있고, 고정한 답변은 다시 묻지 않습니다.
- 저장한 답변은 데이터베이스 백업에 포함됩니다.

**Config › AI**
- AI 설정 탭을 추가했습니다.
- 저장한 답변 수와 이번 달 및 전체 대략적인 비용을 표시합니다. 답변은 JSON으로 내보내고 가져올
  수 있습니다.

**결정판 탭의 AI**
- 각 게임 페이지에서 어느 버전의 콘텐츠가 가장 많은지, 그래픽·사운드·편의성이 가장 좋은지 AI에
  물을 수 있습니다. 답변에는 검토된 노트와 같은 형식의 등급이 붙습니다.
- 브라우저 링크로 얻은 답변은 붙여 넣거나, 클립보드에서 클릭 한 번으로 저장할 수 있습니다.
- 첫 질문 전에 비용 안내를 표시합니다. Config › AI에 각 제공자의 사용 한도 페이지 링크를
  추가했습니다.
- "AI로 일괄 평가"로 여러 게임을 하나의 작업으로 물을 수 있습니다. 대상은 결정판 탭에서 고른
  게임, 또는 세트의 고른 행이나 세트 전체입니다. 시작 전에 질문 수와 대략적인 비용을 표시하고,
  이미 답변이 있는 게임은 건너뜁니다. 세트는 예약할 수도 있습니다.
- 평가 후에 새 버전이 나온 게임에는 "평가 후 새 버전 있음"을 표시하며, 필터에서 제외할 수도
  있습니다.

**타이틀: 하위 버전과 버전 세트**
- "하위판 숨기기"를 추가했습니다. 같은 기종과 지역에 상위판(인터내셔널판, 디렉터스 컷,
  파이널 믹스 등)이 있는 타이틀을 표시하지 않습니다. 이지 타입 등은 일반판 쪽을 남깁니다.
  타이틀, 릴리스, 타이틀 페이지의 릴리스 목록에서 쓸 수 있습니다.
- "버전 세트마다 하나"을 추가했습니다. 포켓몬, 요괴워치처럼 여러 버전으로 나온 게임을
  하나만 표시합니다. 가지고 있는 것, 고른 것, 무작위 순으로 고르며 🎲로 바꿀 수 있습니다. 같은
  세트의 버전은 결정판 탭에서 같은 패밀리로 묶지 않게 되었습니다.
- 타이틀 페이지에 "버전" 카드를 추가했습니다. 두 가지를 모두 확인하고 직접 고칠 수 있습니다.

**Config › 고급**
- 데이터베이스를 망가뜨리거나 파일을 잃을 수 있는 작업을 모은 탭을 추가했습니다. DB 최적화는
  작업과 데이터 › DB에서 이곳으로 옮겼습니다.

**ROM 오디오**
- 타이틀 페이지에서 ROM 안의 음악을 재생할 수 있습니다(지원 플랫폼, 지원 미디어 형식만).
- 설정에서 재생할 트랙의 기준을 조정할 수 있습니다.
- 원음 형식의 음악 파일(NSF, SPC, GBS, VGM, HES, KSS, AY, SAP, 게임기어 SGC, zip 그대로도 가능)을
  지원합니다.
- 원음 파일 라이브러리를 지원합니다. 설정 › 오디오에서 폴더를 지정하면 "ROM 오디오 색인"가 각
  세트를 내용으로 ROM과 대조합니다. 이름이 달라도 지역별 ROM 모두에서 재생됩니다.
- 타이틀 페이지 플레이어에 "이 곡 재생 안 함" 버튼을 추가했습니다. 숨긴 곡은 재생 목록 아래에
  표시되며, 클릭하면 들어 볼 수 있고 "복원"으로 되돌릴 수 있습니다.
- 재생을 위해 디코딩한 ROM 음악을 메모리에 캐시합니다(설정 › 오디오, 기본 256 MiB). 넘치는 곡은
  디스크의 오디오 캐시로 옮기며, 티어 1 캐시 폴더를 설정했다면 그곳을 씁니다.
- 플레이어의 노멀라이즈를 조정했습니다.
- 플레이어에서 크로스페이드를 쓸 수 있습니다(기본 2000ms, 0이면 끔).
- 곡 끝의 무음을 잘라 냅니다. ROM의 곡은 무음을 자르고, 오디오 파일은 오디오 스캔에서 소리가
  끝나는 지점을 기록합니다(이전에 스캔한 파일은 다시 스캔하세요).
- 타이틀 페이지의 음악을 기본으로 켰습니다. 첫 실행 때 언어 다음에 음악을 재생할지 묻습니다.
  자체 오디오가 없는 타이틀에서는 기본으로 무작위 곡을 재생합니다.
- PSF, PSF2 재생에는 컬렉션에 있는 PS2 BIOS를 사용합니다. BIOS가 없으면 건너뜁니다.

**통합 검토와 통합 타이틀**
- 카드의 릴리스를 올바른 타이틀로 끌어서 옮길 수 있습니다. "+"에 놓으면 새 타이틀이 되고 첫
  릴리스의 이름이 붙습니다. 릴리스를 탭한 다음 타이틀을 탭해도 옮길 수 있습니다.
- 채택하거나 거절한 카드도 상태 필터로 표시할 수 있습니다. 기본으로는 표시하지 않습니다.
- 분할도 편집 › 통합 타이틀에 기록되어 그곳에서 되돌릴 수 있습니다. 이 업데이트 전에 통합
  검토에서 분할한 것도 목록에 추가됩니다.

**릴리스 합치기**
- 따로 등록된 같은 게임의 디스크(번들의 디스크, 특전 디스크 등)를 선택해 "하나의 릴리스로 합치기"로 묶을 수 있습니다. 목록에는 대표 릴리스 하나만 표시되고, 복사하면 모든 디스크가 복사됩니다. 릴리스 페이지에서 다시 분리할 수 있습니다.

**스캔**
- 파일 페이지에 "이 파일 다시 스캔"을 추가했습니다. ROM의 나머지와 함께 파일을 다시 읽고, 그 게임을 바로
  릴리스에 대조합니다.
- 파일 페이지에 파일이 연결된 릴리스와 타이틀을 표시합니다.

## 버그 수정

- 단어 중간에 하이픈이 있는 이름이 IGDB 표기와 맞지 않아 IGDB에 매칭되지 않던 게임이 있었습니다. SNES와 NES의 IGDB 동기화에서 일본 전용 게임이 빠지던 문제도 수정했습니다.
- IGDB 연결을 해제해도 IGDB의 다른 이름이 타이틀에 남아 삭제할 수 없던 문제를 수정했습니다. 연결을 해제하면 함께 사라지며, 다른 이름은 ✕로 하나씩 삭제할 수 있습니다.
- 직접 해제한 IGDB 연결이 메타데이터 업데이트 때 다시 연결되던 문제를 수정했습니다. 직접 다시 연결할 때까지 해제된 상태로 유지됩니다.
- RetroAchievements 서브셋(챌린지, 스피드런 등)이 게임의 타이틀에 들어가, 한 게임의 두 버전이 하나의 타이틀로 묶이는 일이 있었습니다. 이제 서브셋은 각각 별도의 타이틀이 되며, 기존 것은 통합 감사가 분리합니다.
- 통합 검토에서 받아들인 통합을 되돌려도 제안이 돌아오지 않았습니다. 이제 다시 검토 대기 상태가 됩니다.
- 타이틀을 직접 통합한 뒤에도 그 통합 제안이 통합 검토에 남아 있었습니다.
- 해적판이나 비공식 게임이 정식 게임의 타이틀에 통합되던 문제를 수정했습니다.
- "다른 게임이 섞여 있음" 카드에서 다른 지역의 해적판이나 비공식 게임이 타이틀에 남던 문제를
  수정했습니다.
- "다른 게임이 섞여 있음" 카드가 이름 앞에 번호가 붙은 릴리스("0743 - …")를 다른 게임으로 다루던
  문제를 수정했습니다.
- 통합 감사 등 작업의 진행 상황을 자세히 표시하도록 수정했습니다.
- DAT에 있는 파일이 릴리스에도 타이틀에도 연결되지 않은 채 남는 문제를 수정했습니다. 스캔 뒤에 DAT를 추가했거나,
  위 폴더 다음에 하위 폴더를 스캔했을 때 일어났습니다.

# romexplorer 0.1.8 (alpha)

알파 버전입니다. 릴리스 사이에 데이터베이스 스키마가 업그레이드 수단 없이 바뀔 수 있습니다.
빌드를 바꾸기 전에 백업하세요.

## 변경 사항

**미디어**
- 새 데이터베이스로 다시 시작할 때, 미디어 폴더에 있는 아트를 다시 다운로드하지 않고 사용합니다.

**작업**
- 작업 목록의 세부 항목을 조정했습니다.
- 대기 중인 작업에 "다음에 실행" 버튼을 추가했습니다. 선택한 작업에도 쓸 수 있습니다. 같은 레인에서
  실행 중인 작업이 끝나면 바로 시작합니다. 다른 레인에는 영향을 주지 않습니다.

**해시 대조**
- Hasheous만 켠 해시 대조에서도 PlayMatch 때와 마찬가지로 대조된 항목의 IGDB 데이터와 아트를
  가져옵니다.
- 설정의 serial_match에서 파일 이름의 시리얼을 쓸지 플랫폼별로 고를 수 있습니다. 고르지 않은
  플랫폼은 파일 이름 체크박스를 따릅니다.

**통합 검토**
- Gemini의 답변과 "Google에 묻기"가 UI 언어로 돌아옵니다.
- 문의에 실패하면 이유를 표시합니다. 인증서나 시간 초과, 모델, 다 쓴 할당량을 알 수 있습니다.
  해당 모델의 무료 할당량이 없는 키는 그렇게 표시합니다.
- 모델 목록을 읽지 못해도 Gemini에 문의합니다. 할당량 오류가 나면 다음 Flash 모델로 한 번
  시도합니다.

**결정판과 크로스플랫**
- IGDB ID가 있는 타이틀만 표시합니다. 타이틀 ID 이름 그대로인 Wii U 타이틀은 결정판 탭에 나오지
  않게 되었습니다.

## 버그 수정

**컬렉션**
- 결정판 탭 검색에서 맨 앞 타이틀 자체의 이름만 찾을 수 있었습니다. 이제 어느 버전의 이름으로도,
  지역 이름이나 별칭으로도 찾을 수 있습니다.
