# romexplorer 0.2.2 (alpha)

알파 버전입니다. 릴리스 사이에 데이터베이스 스키마가 업그레이드 수단 없이 바뀔 수 있습니다.
빌드를 바꾸기 전에 백업하세요.

## 변경 사항

**ROM 오디오**
- ROM 음악 인덱스가 여러 ROM을 동시에 읽을 수 있도록 변경했습니다(기본값 4, 오디오 설정에서 변경 가능).
- 타이틀마다 우선순위가 가장 높은 사본만 인덱싱하고, 음악이 없을 때만 다른 사본을 읽도록 변경했습니다.
- 여러 장으로 된 게임에서 앞 디스크에 있는 음악 파일을 다시 읽지 않도록 변경했습니다.
- 음악 위치를 이미 알고 있는 카트리지 게임은 인덱스를 기다리지 않고 타이틀 페이지를 열면 바로 재생하도록 변경했습니다.

# romexplorer 0.2.1 (alpha)

알파 버전입니다. 릴리스 사이에 데이터베이스 스키마가 업그레이드 수단 없이 바뀔 수 있습니다.
빌드를 바꾸기 전에 백업하세요.

## 변경 사항

**3DS**
- 3DS ROM의 형식 변환을 지원합니다.
- 키는 포함되어 있지 않습니다. aes_keys.txt(필요한 타이틀에는 seeddb.bin도)를 파일과 같은 폴더,
  romexplorer와 같은 폴더 또는 그 assets 폴더에 두세요.
- 3DS ROM의 시리얼 대조를 지원합니다.

**ROM 오디오**
- 타이틀 페이지를 열면 그 게임의 ROM 음악을 먼저 인덱싱하도록 변경했습니다.
- ROM 음악 인덱스를 작은 ROM부터 읽고, 지원하지 않는 ROM은 건너뛰도록 변경했습니다.
- 자체 사운드 엔진을 쓰는 PS1 게임을 지원합니다.

## 버그 수정

- 읽는 데 오래 걸리는 ROM이 있으면 ROM 음악 인덱싱이 멈춘 것처럼 보이던 문제를 수정했습니다.
- DAT 대조로만 식별된 ROM이 ROM 음악 인덱스에서 빠지던 문제를 수정했습니다.
- 내부 제목이 가타카나인 일본 슈퍼 패미컴 ROM의 기종을 스캔에서 판정하지 못하던 문제를 수정했습니다.
- 타이틀 페이지에 게임의 사본마다 같은 음악이 반복해서 표시되던 문제를 수정했습니다.
- 일부 디스크 이미지에서 ROM 음악 인덱싱이 끝나지 않던 문제를 수정했습니다.
- 복사에서 SNES 덤프를 변환할 때, 크기와 내부 헤더의 카피어 헤더 유무가 맞지 않는 파일도 그대로
  변환하던 문제를 수정했습니다.

**스캔**
- Linux에서 대소문자나 "\" 구분자가 다른 cue·gdi·m3u 항목을 놓치던 문제와, 대소문자만 다른 두 파일을
  하나의 ROM으로 보던 문제를 수정했습니다.
- 안쪽 폴더에 설정한 종류·기종이 상위 폴더 스캔에서 무시되던 문제를 수정했습니다.
- 다시 스캔할 때 폴더형 게임을 다시 읽고, 트랙을 분리하고, 시리얼 대조가 풀리던 문제를
  수정했습니다. 큰 폴더에서 디스크 묶기를 빠르게 했습니다.
- ROM이 아닌 파일(텍스트·이미지)은 대조되었을 때만 게임으로 만들도록 변경했습니다.
- 스캔 해시에서 crc32·md5·sha1 중 하나를 필수로 변경했습니다. xxh3_128만으로 DAT 대조가 풀리던
  문제를 수정했습니다.

**복사**
- 덮어쓸 때 새 파일보다 먼저 이전 파일을 지우던 문제, 유지하도록 설정한 재생 목록을 다시 쓰던
  문제, 대소문자만 다른 두 파일을 하나로 쓰던 문제를 수정했습니다.

**타이틀 통합**
- 버전 세트의 다른 버전끼리나 정규판과 비정규판을 통합하던 문제를 수정했습니다. "모두 승인"으로
  해제한 통합이 되돌아오던 문제, 감사에서 뺀 IGDB 링크가 되돌아오던 문제도 수정했습니다.
- 통합된 게임의 별칭으로 Hasheous 대조를 하면 타이틀이 중복되던 문제를 수정했습니다.

**서버와 작업**
- 클라이언트용 아트 가져오기가 서버 내부 네트워크에 접속할 수 있던 문제를 수정했습니다. 크기
  상한도 추가했습니다.
- "database"·"all" SQLite 캐시 다운로드를 관리자 전용으로 변경했습니다.
- 전체 동기화가 중단되면 테이블이 절반만 남던 문제, 백업을 취소한 뒤 쓰는 중에 다음 백업이 시작되던
  문제를 수정했습니다.
- 다른 드라이브로의 복사나 다른 서버에서의 동기화가 관계없는 작업을 기다리던 문제, 데이터베이스
  재시작 후 작업이 두 번 시작되던 문제를 수정했습니다.

**기타**
- PSF2 세트에서 ROM 음악 처리가 멈추던 문제를 수정했습니다.
- 웹 콘솔과 설정 화면의 일부가 영어로 남아 있던 문제를 수정했습니다.
- 10.6 이전 MariaDB는 연결할 때 오류를 표시하도록 변경했습니다.

# romexplorer 0.2.0 (alpha)

## 변경 사항

**통합 검토의 AI**
- "Google에 묻기"를 Ask 메뉴로 변경했습니다. Google의 AI 모드·Claude·ChatGPT·Perplexity를 질문을
  넣은 상태로 브라우저에서 엽니다.
- 앱 안의 답변에는 Gemini·Claude·OpenAI·Perplexity를 쓸 수 있습니다. 각각 API 키와 모델을
  설정합니다.
- 답변을 저장하도록 변경했습니다. "다시 묻기"로 다시 가져오며, 고정한 답변은 자동으로 다시
  가져오지 않습니다.
- 저장한 답변은 데이터베이스 백업에 포함됩니다.

**Config › AI**
- AI 설정 탭을 추가했습니다.
- 저장한 답변 수와 이번 달·전체의 예상 비용을 표시합니다. 답변은 JSON으로 내보내고 가져올 수
  있습니다.

**결정판 탭의 AI**
- 각 게임 페이지에서 결정판을 고르기 위해 타이틀 간의 차이를 AI에 물을 수 있습니다. 답변에는
  주석과 같은 형식의 등급이 붙습니다.
- 첫 질문 전에 비용 안내를 표시합니다. Config › AI에 각 제공자의 사용 한도 페이지 링크를
  추가했습니다.
- "AI로 일괄 평가"로 여러 게임을 한 작업에서 물을 수 있습니다. 시작 전에 질문 수와 예상 비용을
  표시하고, 답변이 있는 게임은 건너뜁니다.
- 평가 후에 새 버전이 나온 게임에는 "평가 후 새 버전 있음"을 표시하며, 필터에서 뺄 수도 있습니다.

**타이틀: 하위 버전과 버전 세트**
- "하위판 숨기기"를 추가했습니다.
- "버전 세트마다 하나"를 추가했습니다.
- 타이틀 페이지에 "버전" 카드를 추가했습니다.

**Config › 고급**
- 데이터베이스를 손상시키거나 파일을 잃을 수 있는 작업을 모은 탭을 추가했습니다. 데이터베이스
  최적화는 작업과 데이터 › DB에서 이곳으로 옮겼습니다.

**ROM 오디오**
- 타이틀 페이지에서 ROM 안의 음악을 재생할 수 있습니다(디스크 게임의 CD 오디오 트랙과 닌텐도
  DS·3DS의 사운드 아카이브).
- 설정에서 재생할 트랙의 기준을 조정할 수 있습니다.
- 타이틀 페이지 플레이어에 "이 곡 재생 안 함" 버튼을 추가했습니다.
- 재생을 위해 디코딩한 ROM 음악을 메모리에 캐시합니다(설정 › 오디오, 기본 256 MiB).
- 플레이어의 노멀라이즈를 조정했습니다.
- 플레이어에서 크로스페이드를 할 수 있습니다(기본 2000ms, 0이면 끔).
- 곡 끝의 무음을 잘라내도록 변경했습니다.
- 타이틀 페이지의 음악을 기본으로 켜도록 변경했습니다. 첫 실행 때 언어 다음에 음악을 틀지
  묻습니다. 자체 음원이 없는 타이틀에서는 기본으로 무작위 곡을 틉니다.

**통합 검토와 통합 타이틀**
- 카드의 릴리스를 올바른 타이틀로 드래그해 옮길 수 있습니다. "+"에 놓으면 새 타이틀을 만들 수
  있습니다.
- 승인·거절한 카드도 상태 필터로 표시할 수 있습니다. 기본으로는 표시하지 않습니다.
- 분할도 편집 › 통합 타이틀에 기록되어 그곳에서 되돌릴 수 있습니다. 이 업데이트 전에 통합
  검토에서 분할한 것도 목록에 추가합니다.

**릴리스 합치기**
- 따로 등록된 같은 게임의 디스크를 골라 "하나의 릴리스로 합치기"로 묶을 수 있습니다.

**스캔**
- 파일 페이지에 "이 파일 다시 스캔"을 추가했습니다. ROM의 다른 파일과 함께 다시 읽고 그 게임을
  바로 릴리스에 대조합니다.
- 파일 페이지에 링크된 릴리스와 타이틀을 표시하도록 변경했습니다.

## 버그 수정

- 단어 중간에 하이픈이 있는 이름이 IGDB 표기와 대조되지 않아 IGDB에 매치되지 않는 게임이 있던
  문제를 수정했습니다.
- SNES와 NES의 IGDB 동기화에서 일본에서만 발매된 게임이 빠지던 문제를 수정했습니다.
- IGDB 링크를 해제해도 IGDB 별칭이 타이틀에 남고 지울 수도 없던 문제를 수정했습니다. 링크 해제로
  사라지며, 별칭은 ✕로 하나씩 지울 수 있습니다.
- 직접 해제한 IGDB 링크가 메타데이터 업데이트 때 다시 연결되던 문제를 수정했습니다. 직접 다시
  연결할 때까지 해제된 상태로 남습니다.
- RetroAchievements 서브셋(챌린지, 스피드런 등)이 게임 타이틀에 들어가 다른 버전이 하나의
  타이틀로 묶이던 문제를 수정했습니다.
- 통합 검토에서 통합한 것을 되돌려도 제안이 통합 검토로 돌아오지 않던 문제를 수정했습니다.
- 직접 통합한 타이틀의 제안이 통합 검토에 남던 문제를 수정했습니다.
- 해적판과 비공식 게임이 시판 게임 타이틀에 통합되던 문제를 수정했습니다.
- "다른 게임이 섞여 있음" 카드에서 다른 지역의 해적판과 비공식 게임이 타이틀에 남던 문제를
  수정했습니다.
- "다른 게임이 섞여 있음" 카드가 이름 앞에 번호가 붙은 릴리스("0743 - …")를 다른 게임으로 다루던
  문제를 수정했습니다.
- 통합 감사 등 작업의 진행 상황을 자세히 표시하도록 수정했습니다.
- Windows arm64와 Linux arm64에서 Wii U·Xbox·Xbox 360 이미지 변환, PBP 읽기, ROM 음악 재생이 되지
  않던 문제를 수정했습니다.
- DAT에 실린 파일이 릴리스에도 타이틀에도 링크되지 않은 채 남던 문제를 수정했습니다.

# romexplorer 0.1.8 (alpha)

## 변경 사항

**미디어**
- 새 데이터베이스로 다시 시작할 때 미디어 폴더에 있는 아트를 다시 쓰도록 변경했습니다.

**작업**
- 작업 목록의 세부 항목을 조정했습니다.
- 대기 중인 작업에 "다음에 실행" 버튼을 추가했습니다.

**해시 대조**
- Hasheous만 켠 해시 대조에서도 IGDB 데이터와 아트를 가져오도록 변경했습니다.
- serial_match에서 파일 이름의 시리얼을 쓸지 플랫폼별로 고를 수 있습니다.

**통합 검토**
- Gemini의 답변과 "Google에 묻기"를 UI 언어로 변경했습니다.
- 문의에 실패하면 이유를 표시합니다.
- 모델 목록을 읽지 못해도 Gemini에 문의하도록 변경했습니다.

**결정판과 크로스플랫**
- IGDB ID가 있는 타이틀만 표시하도록 변경했습니다.

## 버그 수정

**컬렉션**
- 결정판 탭 검색에서 맨 앞 타이틀의 이름만 찾을 수 있던 문제를 수정했습니다.
